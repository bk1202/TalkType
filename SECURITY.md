# Security policy

TalkType handles microphone audio and dictated text, so privacy bugs are treated
as security issues.

Please do not open a public issue for vulnerabilities that could expose audio,
transcripts, local files, or arbitrary code execution. Once the repository is
published, report them privately through GitHub's **Security advisories** page.

The supported branch is `main`. Security fixes will be included in the next
available release and documented without exposing users before a fix exists.
